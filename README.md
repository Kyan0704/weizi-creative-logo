# Weizi Creative Logo · 维兹风格创意Logo设计技能

> 以"少即是多，巧即是妙"为核心理念的 AI Agent 技能，通过设计减法和创意同构，用最少的视觉元素传达最丰富的品牌含义。

## 设计理念

维兹风格拒绝"A+B简单拼贴"的烂大街首字母logo，坚持每个图形必须同时承载至少两层含义。通过设计减法删到临界点，用负空间、字母共笔、图形同构等手法，让logo既极简又巧妙。

## 十大核心手法

| 手法 | 核心逻辑 | 典型效果 |
|------|----------|----------|
| 设计减法 | 删到临界点的极简 | 墨镜+嘴唇=时尚人物 |
| 负空间双关 | 留白中藏第二意象 | 嘴唇中藏手指/领带 |
| 实物切入点 | 从日常实物提取轮廓 | 婴儿脚丫→母婴品牌 |
| 字母共笔 | 两字母共享笔画 | S+J→优雅S形整体 |
| 图形同构 | 形状相似处融合 | 星星+芒果 |
| 圆切手法 | 辅助圆切割有机图形 | 八瓣茉莉花 |
| 描边轮廓 | 统一线宽空心线描 | 线性动物头像 |
| 字母意象化 | 字母笔画变形为符号 | O+流星 |
| 替换笔画 | 字体笔画替换为图形 | "茶"横→茶叶 |
| 留白传统图样 | 传统图形现代减法 | 窗花极简重构 |

## 安装使用

将本仓库克隆或复制到 AI Agent 的用户技能目录（`.user_skills/`）下，重启 Agent 后即可自动触发。

触发关键词：设计logo、标志、商标、品牌标识、创意logo、极简标志、负空间设计、字母组合logo、品牌vi

## 工作流

1. **品牌拆解** — 提取品牌名、首字母、行业、关键词
2. **手法匹配** — 从十大手法中选2-3种
3. **草图构思** — 每种手法2个方向，共4-6个初稿
4. **精修定稿** — 选中2-3个方案规范曲线比例
5. **生成图片** — 调用 image_gen 按模板生成logo
6. **方案呈现** — 多方案对比 + 设计思路说明
